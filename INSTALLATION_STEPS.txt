█████████████████████████████████████████████████████████████████████
█                                                                   █
█   STEP 1: DOWNLOAD & INSTALL XAMPP                               █
█                                                                   █
█████████████████████████████████████████████████████████████████████

1. Buka browser, kunjungi:
   🔗 https://www.apachefriends.org

2. Download XAMPP sesuai sistem operasi:
   🪟 Windows
   🍎 Mac OS X
   🐧 Linux

3. Install XAMPP:
   ▶ Klik installer yang sudah didownload
   ▶ Ikuti wizard instalasi
   ▶ Install di lokasi default (C:\xampp atau /Applications/XAMPP)

4. Selesai? ✓ Lanjut ke Step 2!


█████████████████████████████████████████████████████████████████████
█                                                                   █
█   STEP 2: JALANKAN XAMPP                                         █
█                                                                   █
█████████████████████████████████████████████████████████████████████

1. Buka XAMPP Control Panel:
   🪟 Windows: Start Menu → XAMPP Control Panel
   🍎 Mac: Applications → XAMPP → manager-osx
   🐧 Linux: Terminal → sudo /opt/lampp/manager-linux.run

2. Klik tombol "Start" pada:
   ┌─────────────┬──────────┐
   │   Module    │  Action  │
   ├─────────────┼──────────┤
   │   Apache    │  [Start] │ ← Klik ini!
   │   MySQL     │  [Start] │ ← Klik ini!
   └─────────────┴──────────┘

3. Tunggu sampai statusnya berubah jadi HIJAU ✓

4. Tes Apache:
   Buka browser → ketik: http://localhost
   Jika muncul halaman XAMPP = SUKSES! ✓


█████████████████████████████████████████████████████████████████████
█                                                                   █
█   STEP 3: SETUP DATABASE DI PHPMYADMIN                           █
█                                                                   █
█████████████████████████████████████████████████████████████████████

1. Buka browser, ketik:
   🔗 http://localhost/phpmyadmin

2. Klik tab "SQL" (di menu atas)
   ┌──────────────────────────────────┐
   │ [Database][SQL][Status][User...] │ ← Klik "SQL"
   └──────────────────────────────────┘

3. Buka file "starsports_database.sql" dengan Notepad atau Text Editor

4. Copy SEMUA isi file tersebut (Ctrl+A, Ctrl+C)

5. Paste ke dalam SQL Query Box di phpMyAdmin
   ┌────────────────────────────────────────┐
   │                                        │
   │  [Paste SQL code disini]               │
   │                                        │
   └────────────────────────────────────────┘

6. Klik tombol "Go" atau "Kirim" (di kanan bawah)

7. Jika sukses, akan muncul:
   ✓ "Query OK, X rows affected..."

8. Cek di sidebar kiri, seharusnya muncul database:
   📁 starsports
      └─ 📄 sepatu (table)

9. Selesai? ✓ Lanjut ke Step 4!


█████████████████████████████████████████████████████████████████████
█                                                                   █
█   STEP 4: COPY FILE APLIKASI KE HTDOCS                           █
█                                                                   █
█████████████████████████████████████████████████████████████████████

1. Cari folder "htdocs" di direktori XAMPP:
   
   🪟 Windows:
      C:\xampp\htdocs\
   
   🍎 Mac:
      /Applications/XAMPP/htdocs/
   
   🐧 Linux:
      /opt/lampp/htdocs/

2. Buat folder baru bernama "starsports" di dalam htdocs
   📁 htdocs
      └─ 📁 starsports ← Buat folder ini!

3. Copy SEMUA file aplikasi ke folder starsports:
   ✓ config.php
   ✓ index.php
   ✓ create.php
   ✓ edit.php
   ✓ update.php
   ✓ delete.php
   ✓ style.css
   ✓ starsports_database.sql
   ✓ README.md

4. Hasil akhir struktur folder:
   📁 htdocs
      └─ 📁 starsports
         ├─ 📄 config.php
         ├─ 📄 index.php
         ├─ 📄 create.php
         ├─ 📄 edit.php
         ├─ 📄 update.php
         ├─ 📄 delete.php
         ├─ 📄 style.css
         ├─ 📄 starsports_database.sql
         └─ 📄 README.md

5. Selesai? ✓ Lanjut ke Step 5!

█   TROUBLESHOOTING - KALAU ADA ERROR                              █
█                                                                   █
█████████████████████████████████████████████████████████████████████

🔴 ERROR: "Cannot connect to database"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - MySQL belum jalan
  - Database belum diimport
  
Solusi:
  1. Cek XAMPP Control Panel
  2. Pastikan MySQL nyala (HIJAU)
  3. Cek database di phpMyAdmin
  4. Ulangi Step 3


🔴 ERROR: "404 Not Found"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - File tidak ada di htdocs
  - URL salah
  
Solusi:
  1. Cek folder: htdocs/starsports/
  2. Pastikan semua file ada
  3. Cek URL: http://localhost/starsports
     (BUKAN: http://localhost/starsports/index.php)


🔴 ERROR: Halaman putih / blank
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - PHP error
  - Syntax error
  
Solusi:
  1. Tekan F12 di browser
  2. Klik tab "Console"
  3. Lihat pesan error
  4. Cek file yang bermasalah


🔴 ERROR: "Undefined index"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - Form field tidak terisi
  
Solusi:
  - Pastikan semua field diisi
  - Field bertanda * wajib diisi


🔴 ERROR: Data tidak tersimpan
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - Validasi gagal
  - Connection timeout
  
Solusi:
  1. Isi semua field
  2. Harga & stok harus angka
  3. Refresh halaman
  4. Coba lagi
