🖼️ FITUR UPLOAD GAMBAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A. UPLOAD SAAT TAMBAH PRODUK
────────────────────────────────
1. Klik "Tambah Produk" di navbar
2. Di form modal, bagian pertama ada "Gambar Sepatu"
3. Klik "Choose File" atau "Browse"
4. Pilih gambar dari komputer (JPG/PNG/GIF/WEBP)
5. Preview akan muncul otomatis
6. Isi data lainnya
7. Klik "Simpan"

✓ Gambar akan diupload ke folder uploads/
✓ Nama file auto-generate (unik)
✓ Thumbnail muncul di tabel


B. LIHAT GAMBAR DI TABEL
────────────────────────────────
1. Di tabel utama, kolom kedua adalah "Gambar"
2. Thumbnail (60x60px) akan tampil
3. Klik thumbnail untuk lihat full size
4. Modal akan muncul dengan gambar besar
5. Klik X atau di luar modal untuk tutup


C. EDIT/GANTI GAMBAR
────────────────────────────────
1. Klik tombol "Edit" (icon pensil) di baris produk
2. Gambar saat ini akan ditampilkan
3. Untuk GANTI gambar:
   → Klik "Choose File"
   → Pilih gambar baru
   → Preview akan update
4. Untuk TIDAK GANTI gambar:
   → Jangan pilih file
   → Gambar lama tetap dipakai
5. Klik "Update Data"

✓ Gambar lama otomatis dihapus (jika diganti)
✓ Hemat storage


D. VALIDASI & ERROR HANDLING
────────────────────────────────
Sistem akan reject jika:
❌ Format bukan JPG/PNG/GIF/WEBP
❌ Ukuran file > 2MB
❌ File corrupt/rusak

Error message akan muncul di top halaman.


🎨 ADMIN PANEL - CUSTOMIZE TAMPILAN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A. AKSES ADMIN PANEL
────────────────────────────────
1. Di navbar, klik "Admin Panel"
   ATAU
2. Akses langsung: http://localhost/starsports/admin.php


B. UBAH INFORMASI SITUS
────────────────────────────────
Section: "Informasi Situs"

1. Nama Situs
   → Ganti "StarSports" jadi nama toko Anda
   → Contoh: "RonaldoShoes", "NikeStore", dll
   
2. Tagline / Slogan
   → Ganti tagline di hero section
   → Contoh: "Sepatu Terbaik untuk Atlet Profesional"
   
3. Icon Logo
   → Ganti icon di navbar
   → Cari di: https://fontawesome.com/icons
   → Copy class name, contoh: "fa-shoe-prints", "fa-store"
   → Preview real-time akan muncul


C. UBAH SKEMA WARNA
────────────────────────────────
Section: "Skema Warna"

1. Warna Primer
   → Warna utama navbar, buttons, links
   → Klik color picker
   → Pilih warna
   → Preview update otomatis
   
2. Warna Sekunder
   → Warna gradient kedua
   → Untuk efek gradient yang smooth
   
3. Warna Aksen
   → Warna highlight (brand name, emphasis)
   → Pilih warna yang kontras

Tips:
✓ Gunakan color wheel untuk kombinasi harmonis
✓ Test kontras: text harus readable
✓ Gunakan brand colors jika ada


D. PENGATURAN TAMPILAN
────────────────────────────────
Section: "Pengaturan Tampilan"

Toggle ON/OFF:

1. Hero Section
   ☑ ON  → Hero banner ditampilkan
   ☐ OFF → Hero banner disembunyikan
   
2. Statistics Cards
   ☑ ON  → Dashboard stats ditampilkan
   ☐ OFF → Dashboard stats disembunyikan

Berguna untuk:
→ Minimalist design (hide semua)
→ Focus pada data (hide hero)
→ Kustomisasi sesuai kebutuhan


E. LIVE PREVIEW
────────────────────────────────
Panel kanan: "Live Preview"

✓ Navbar preview dengan warna real-time
✓ Hero section text preview
✓ Color scheme bars
✓ Update otomatis saat edit

Catatan: Preview hanya perkiraan, lihat hasil
         sebenarnya setelah save & refresh home.


F. SIMPAN PERUBAHAN
────────────────────────────────
1. Setelah selesai edit semua
2. Scroll ke bawah
3. Klik tombol besar "Simpan Perubahan"
4. Success alert akan muncul
5. Klik "Kembali ke Home" di navbar
6. REFRESH halaman (F5 atau Ctrl+R)
7. Lihat perubahan!

🔴 ERROR: "Failed to upload image"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  1. Folder 'uploads' tidak ada
  2. Folder 'uploads' tidak writable
  3. File terlalu besar (>2MB)
  4. Format file tidak didukung

Solusi:
  1. Pastikan folder uploads/ ada di htdocs/starsports/
  2. Set permissions: chmod 777 uploads/ (Linux/Mac)
     atau Properties → Security → Full Control (Windows)
  3. Compress gambar jika terlalu besar
  4. Gunakan JPG/PNG/GIF/WEBP only


🔴 ERROR: Gambar tidak muncul di tabel
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - Path gambar salah
  - File tidak terupload

Solusi:
  1. Cek folder uploads/, apakah file ada?
  2. Cek database, kolom 'gambar', apakah ada nama file?
  3. Refresh halaman (Ctrl+F5)


🔴 ERROR: "Default.jpg not found"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - File default.jpg tidak ada

Solusi:
  1. Copy file default.jpg ke folder uploads/
  2. Atau buat file SVG sendiri (lihat README)


🔴 ERROR: Admin panel tidak bisa save
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - Tabel 'settings' tidak ada
  - Database belum diupdate

Solusi:
  1. Import file starsports_update.sql
  2. Refresh phpMyAdmin, cek tabel 'settings' ada?


🔴 ERROR: Perubahan warna tidak terlihat
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - Browser cache
  - Belum refresh

Solusi:
  1. Hard refresh: Ctrl+Shift+R atau Ctrl+F5
  2. Clear browser cache
  3. Tutup & buka browser lagi


🔴 WARNING: Move_uploaded_file failed
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Penyebab:
  - Permission denied

Solusi:
  Windows:
    1. Klik kanan folder htdocs/starsports/
    2. Properties → Security
    3. Edit → Add "Everyone" → Full Control
    
  Linux/Mac:
    1. Terminal: cd /path/to/htdocs/starsports
    2. chmod -R 777 uploads/
    3. chown -R www-data:www-data uploads/ (Linux)
