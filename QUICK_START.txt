🚀 INSTALASI SUPER CEPAT (5 MENIT!)

LANGKAH 1: PERSIAPAN
────────────────────
1. Install XAMPP (jika belum ada)
   Download: https://www.apachefriends.org
   
2. Jalankan XAMPP Control Panel
   
3. Klik "Start" pada:
   ☑ Apache
   ☑ MySQL


LANGKAH 2: SETUP DATABASE
─────────────────────────
1. Buka browser, akses: http://localhost/phpmyadmin
   
2. Klik tab "SQL"
   
3. Buka file: starsports_database.sql dengan Notepad
   
4. Copy SEMUA isinya
   
5. Paste ke SQL Query Box di phpMyAdmin
   
6. Klik tombol "Go" / "Kirim"
   
7. ✓ Database "starsports" sudah terbuat!


LANGKAH 3: SETUP APLIKASI
──────────────────────────
1. Copy SEMUA file ke folder htdocs XAMPP:
   
   Windows  : C:\xampp\htdocs\starsports\
   Mac      : /Applications/XAMPP/htdocs/starsports/
   Linux    : /opt/lampp/htdocs/starsports/
   
   Catatan: Buat folder "starsports" terlebih dahulu!
   
2. Struktur folder harus seperti ini:
   
   starsports/
   ├── config.php
   ├── index.php
   ├── create.php
   ├── edit.php
   ├── update.php
   ├── delete.php
   ├── style.css
   ├── starsports_database.sql
   └── README.md


LANGKAH 4: JALANKAN APLIKASI
────────────────────────────
1. Buka browser
   
2. Ketik: http://localhost/starsports
   
3. SELESAI! Aplikasi siap digunakan! 🎉

  2. Konfirmasi penghapusan

🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ MASALAH: "Cannot connect to database"
✓ SOLUSI:
  - Pastikan MySQL di XAMPP sudah running (hijau)
  - Cek username & password di config.php
  - Default XAMPP: user=root, password=kosong

❌ MASALAH: "404 Not Found"
✓ SOLUSI:
  - Pastikan Apache sudah running
  - Cek URL: http://localhost/starsports (tanpa .php)
  - Pastikan file ada di folder htdocs/starsports/

❌ MASALAH: "Data tidak tersimpan"
✓ SOLUSI:
  - Pastikan semua field diisi
  - Cek validasi (harga & stok harus angka positif)
  - Tekan F12, cek Console untuk error
